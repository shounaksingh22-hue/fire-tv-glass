# Fire TV debloat catalog — what to disable, and what to KEEP on purpose.
# Format:  package | category | what it is
# setup.sh plan  offers only packages that exist on the TV as enabled system apps and are not in
# that TV's protected.txt. Lines starting with "#" are never offered. Everything is reversible:
#   adb shell pm enable --user 0 <package>
# Verified on Fire OS 7.7.1.5 (AFTDCT31 Fire TV Edition TV), Oct 2026.

## KEEP ON PURPOSE (never offered) — why
# com.amazon.tv.launcher                     | stock home: Fire OS needs it; disabling risks a TV with no home screen
# com.amazon.firehomestarter                 | starts the stock home on boot
# com.amazon.venezia                         | Appstore: updates Netflix, Prime, HBO, etc. (hide it in Glass instead)
# com.amazon.tv.livetv                       | Live TV / channel guide (user wanted Live TV)
# com.amazon.providers.contentsupport        | content provider other apps depend on; breaks things on Fire OS 7
# com.amazon.tv.ottssocompanionapp           | app sign-in companion (sign in with phone)
# com.amazon.vizzini                         | Alexa voice (voice button on the remote)
# com.amazon.alexa*  com.amazon.whad          | Alexa media / voice UI
# com.amazon.aca  com.amazon.adep             | account sync / Amazon Security
# com.amazon.prism.android.service            | profiles
# com.amazon.awvflingreceiver  com.amazon.dialservice  com.amazon.whisperplay.service.install
#                                            | casting (phone -> TV, incl. YouTube/TizenTube casting)
# com.amazon.cast.sink                       | Miracast screen mirroring
# com.amazon.tv.forcedotaupdater.v2  com.amazon.tv.easyupgrade
#                                            | system updates (security) — keep unless you really mean it
# com.amazon.ceviche  com.fireos.sdk.ftve.addp | unknown role; not worth the risk
